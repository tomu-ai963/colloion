# Colloion — コロイド電解ノート

コロイド・イオン溶液の電解調製を記録／計算する個人実験ノートです。
医療・健康目的の製品ではなく、効能に関する情報は一切扱いません。

サーバ不要のローカル完結（IndexedDB 永続化）で、作業場でオフラインでも動きます。

## 使い方

```bash
npm install
npm run dev        # 開発サーバ
npm run build      # 本番ビルド（GitHub Pages 向け base=/colloion/）
npm run typecheck  # 型検査
npm run lint       # ESLint
npm run test       # Vitest（core の単体テスト + 主要 UI テスト）
```

## 構成

```
src/
  core/       UI 非依存の計算ロジック（ここだけでテストが完結）
  store/      Zustand ストアと派生計算（derive）
  storage/    StorageAdapter インターフェース + IndexedDB / メモリ実装
  ui/         パネル・共通コンポーネント・readout
docs/mock.html  参照用 UI モック
```

同期機能（Cloudflare Workers + D1）は Phase 3 の想定で、現在は
`StorageAdapter` インターフェースの差し替え口だけを用意しています。

## 計算式の根拠

### ファラデーの電気分解の法則

電極で反応する物質の量は、流した電気量（電荷）に比例します。
陽極から溶出する金属の質量は

```
m [g] = (M / (n × F)) × Q × η
```

- `M` : 金属の原子量 [g/mol]
- `n` : 溶出イオンの価数（Ag⁺ なら 1、Zn²⁺ なら 2）
- `F` : ファラデー定数 96485 C/mol（電子 1 mol あたりの電荷）
- `Q` : 積算電荷 [C] ＝ 電流 [A] × 時間 [s]
- `η` : 電流効率。流れた電荷のうち目的の溶出反応に使われた割合

### 電気化学当量

`M / (n × F)` は「1 クーロンあたりに溶出する質量」で、電気化学当量と呼びます。
本アプリではこの値をハードコードせず、原子量と価数から毎回導出しています
（`src/core/metals.ts` の `electrochemicalEquivalent`）。

| 金属 | M [g/mol] | n | 当量 [mg/C] |
|---|---|---|---|
| Ag | 107.868 | 1 | 1.118 |
| Au | 196.967 | 3 | 0.681 |
| Cu | 63.546 | 2 | 0.329 |
| Zn | 65.38 | 2 | 0.339 |
| Mg | 24.305 | 2 | 0.126 |
| Fe | 55.845 | 2 | 0.289 |
| Mn | 54.938 | 2 | 0.285 |

濃度は希薄水溶液の近似 `1 mg/L ≒ 1 ppm` で

```
ppm = m [mg] / 水量 [L]
```

逆算（目標 ppm → 必要時間）は同じ式を時間について解いたもので、
順算と往復で一致することをテストで保証しています。

### ファラデー則が成立しない金属

- **Mg** — 水と直接反応して自己腐食するため（負差効果）、実効の電流効率が
  130〜200% と 100% を超えます。理論値は**下限**としてのみ表示します。
  UI の効率スライダー上限が 200% なのはこのためです。
- **Ca** — 金属カルシウムは水と激しく反応するため電解不可（当量 0）。
- **Pt** — 不溶性電極。逆算は `null`（到達不能）を返します。

### 母液（ストック溶液）

```
モル濃度 [mol/L] = (秤量 [g] × 含量% / 100) / 分子量 / (溶媒量 [mL] / 1000)
```

母液は**濃度で保存**するため、仕込み水量が変わっても目標 mmol/L を保つ
滴数を逆算できます。1 滴の体積はスポイト依存（0.03〜0.06 mL）なので、
20 滴の実測体積からキャリブレーションし、その値は試薬ではなく
**器具（スポイト）に紐づけて**保存します。

### 分子量

化学式パーサー（`src/core/formula.ts`）が原子量テーブルから算出します。
水和物のドット記法（`Na2CO3·10H2O`）に対応しており、無水と水和物では
分子量が大きく違う（無水 105.99 / 十水和物 286.14 で 2.7 倍）ため、
水和物の登録時には警告を出します。

## 表示値についての注意

- **ppm は理論値**です。実測（TDS・pH）は記録タブで別に入力し、
  ラベルで明確に区別して表示します。
- **推定粒径は経験的な近似式**（電流密度と濃度からの目安）であり、
  TEM や DLS による測定値ではありません。
- **TDS メーターは導電率**を測っており、イオン性の金属しか検出しません。
  粒子化が進むと数値はむしろ下がるため、「TDS が伸びない＝失敗」ではありません。
- イオンモードでチンダル光条が消えるのは演出ではなく仕様です。
  真の溶液は光を散乱しません。
